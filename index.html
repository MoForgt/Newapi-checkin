各平台配置指南

坚果云
  • WebDAV 地址：https://dav.jianguoyun.com/dav/邮箱/
  • 密码需使用「应用密码」：账户信息 → 安全选项 → 第三方应用管理 → 添加应用密码
  • 官方文档 ↗
群晖 NAS
  • 套件中心安装 WebDAV Server，启用 HTTP / HTTPS
  • HTTPS 端口 5006，HTTP 端口 5005，地址格式 https://NAS域名:5006/webdav/
  • 官方文档 ↗
NextCloud
  • WebDAV 地址：https://域名/remote.php/dav/files/用户名/
  • 启用 2FA 时需在个人安全设置中创建应用密码
  • 官方文档 ↗
GitHub Actions 接入
  • 保存到云端后，把 CONFIG_URL 与 CONFIG_AUTH 加入仓库 Settings → Secrets
  • 签到脚本优先从云端拉取配置，失败时回退到 NEWAPI_ACCOUNTS
CORS 跨域限制怎么办
  • 浏览器直接打开本文件（file://）时受限最小，推荐优先这样用
  • 群晖 / NextCloud 可在服务端添加 Access-Control-Allow-Origin 响应头
  • 坚果云不支持自定义 CORS，可临时启用上方「CORS 代理」
  • ⚠️ 代理意味着账号密码会经第三方转发，请勿用于敏感账号

导入 JSON 配置

粘贴已有的 JSON 配置，按站点自动分组回填表单。

使用提示

  • 站点分组：同一站点的 URL 与 CF Clearance 只填一次，站点下可添加多个账号
  • 账号信息：每个账号填写 Session 或系统访问令牌（推荐令牌）、用户 ID 和备注；令牌在站点「个人设置」中生成，不依赖 Session 且支持 Turnstile 站点
  • 保存到本地：配置存于浏览器本地存储，下次打开自动提示恢复
  • 明文存储：数据以明文保存在浏览器中，请注意使用环境安全

🧷 站点一键抓取书签

把下面这个书签拖到收藏夹。在任意已登录的 NewAPI 站点点击它，即可自动抓取站点地址、用户 ID 和系统访问令牌，并回填到本页。

🧷 抓取签到配置
① 把按钮拖到收藏夹栏，或点「复制书签代码」后手动新建书签；
② 打开任意已登录的 NewAPI 站点，点击该书签；
③ 确认后自动回填本页，支持连续抓取多个站点并累计暂存。
⚠️ 每次抓取都会重新生成该站点的系统访问令牌，旧令牌随即失效。
